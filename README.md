# PaisaPilot

A friendly, interactive money companion for students and first-time earners. Built with HTML, CSS, vanilla JavaScript, and Python's standard library.

## Run it

1. Open a terminal in this folder.
2. Run `python app.py` (or `py app.py` on Windows).
3. Visit [http://127.0.0.1:8000](http://127.0.0.1:8000).

Your changes are saved in `paisa_data.json` next to the app. No third-party Python packages are required.

## Included

- Responsive dashboard with spending trend and category breakdown
- Add income and expense transactions
- Monthly budget overview and savings goals
- Recurring-payment reminders
- “Can I afford this?” check against remaining monthly budget
- On-device JSON persistence through the local Python server
